# 🌷 Selected Web Projects — Front-End & Logic

A curated collection of web applications and interactive interfaces exploring programming logic, dynamic state architecture, and semantic styling.

Each project addresses a distinct technical challenge — progressing from core DOM manipulation and recommendation logic to object-oriented architectures and bespoke design systems.

---

## 📚 Projects

### 🌷 [Book Bouquet](./book-bouquet)
**Curated Literary Experience · Dynamic DOM Logic**

An interactive literary curation tool. Users select a desired quantity of books, and the engine dynamically generates a randomized "book bouquet" with responsive card compositions and contextual metadata.

* **Core Focus:** Dynamic DOM scripting, random selection algorithms, array/collection traversal, and reactive state feedback.
* **Tech:** HTML5 • CSS3 • JavaScript

---

### 📖 [Entrelinhas](./entrelinhas)
**Reflective Journal · Editorial Typography & Semantics**

A digital reading and reflective writing space designed with a strong focus on accessibility, fluid responsive scales, and custom CSS design tokens without builder bloat.

* **Core Focus:** Semantic HTML5 architecture, fluid typography formulas (`clamp`), CSS custom properties, and WCAG accessibility standards.
* **Tech:** Semantic HTML5 • Modern CSS3 • Responsive Design

---

### 🌿 [Little Garden](./little-garden)
**Interactive Plant Ecosystem · OOP Architecture & State**

A browser-based botanical ecosystem where entities manage dynamic life cycles. Each plant encapsulates individual moisture metrics, decay timers, and hydration thresholds.

* **Core Focus:** Object-Oriented Programming (OOP) in TypeScript, event-driven state updates, lifecycle timers, and clean separation between business logic and the DOM layer.
* **Tech:** TypeScript • OOP • DOM Events • Modern CSS

---

## 🎯 Architecture & Craft Principles

* **Intentional Structure:** Clean separation of concerns between state logic, markup, and presentation.
* **Aesthetic Polish:** Bespoke typography and balanced visual rhythm rather than cookie-cutter templates.
* **Zero Bloat:** Prioritizing native browser capabilities, semantic elements, and lightweight vanilla implementations.
